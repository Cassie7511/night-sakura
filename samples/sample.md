# Cherry Blossom

A personal dark theme in the palette of [my site](https://cassie7511.github.io).

## Palette

- **Near-black** `#0d0d0f` for the frame, `#17171a` for the editor
- *Grays* for text, with cherry-blossom pink for highlights

### Rebuilding

> Edit `palette.js`, then run the build.

```bash
node build.js
```

| Role | Color |
|------|-------|
| keyword | pink |
| string | sage |
